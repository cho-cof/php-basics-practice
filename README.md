# php-basics-practice

## 概要

COACHTECH 教材 Tutorial 7-1「PHPの基礎 ハンズオン演習」で作成した成果物です。

商品価格をもとに、税額や税込価格を計算して表示する簡単な PHP プログラムを作りました。変数や演算子、文字列展開の基礎を確認しています。

## 使用技術

- PHP 8.x

## 学んだこと

- 変数を使って値を保存し、計算に利用できることを理解した。
- 演算子を使って税額や税込価格を求める処理を作れた。
- 文字列展開を使って結果を分かりやすく出力する方法を学んだ。

## 動作確認

- ローカルサーバーを起動し、
  `http://localhost:8000/7-1-6_hands-on/practice/price_calculator.php`
  にアクセスして計算結果が正しく表示されることを確認した。
- 変数の値を変更して再度アクセスし、計算結果が正しく更新されることを確認した。
